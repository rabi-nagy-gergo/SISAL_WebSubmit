SISAL Web Submit

Project Repository

The SISAL Web Submit project transforms an existing local data submission workflow into an interactive web application designed for uploading, auditing, and validating speleothem data. The SISAL speleothem database is one of the largest databases of its kind in the world. This application automates the validation process by providing a user-friendly interface connected to a stateless, file-system-based FastAPI backend.

Submission Workflow
  • File Upload: The contributor fills out the provided Excel workbook template with their speleothem sample data and uploads it through the web interface.
  • Validation (AutoQC): The FastAPI backend executes a Python QC script (wb_check_v15.py) to validate the workbook's content and structure. This script generates a QC log, a regional site map, and a QC-passed copy of the workbook if no structural or logical errors are found.
  • Age-Model & Proxy Plotting: An R plotting script (run_plots.R) is executed to generate a PDF for each entity containing age models, potential hiatuses, and proxy time-series plots.
  • Download and Finalization: The contributor can download a .zip archive containing the validated Excel file and the PDF plots. The validated data and documentation are then manually forwarded to a SISAL Data Steward.
Architecture & Environment
  • Session management allows users to safely save their progress and resume the upload process within a 1-week window.
  • Strict data privacy is enforced by retaining uploaded data for a maximum of 1 week, after which all files are automatically and permanently deleted.
  • Full Docker integration ensures smooth development and deployment by containing all necessary software packages and dependencies in a single, unified environment.
  • The web interface completely eliminates the need for users to manually install and maintain local software packages previously required for the data submission workflow.
  • The application guarantees compatibility by always supporting and validating the most up-to-date SISAL Excel workbook format.
Technology Stack
Python FastAPI R Vanilla JS & HTML Bootstrap 5 Docker
  • Data Validation (Python): Requires pandas, numpy, openpyxl, xlrd, matplotlib, cartopy, and shapely.
  • Plotting (R): Requires openxlsx and ggplot2.
